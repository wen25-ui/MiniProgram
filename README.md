# 微信小程序业务返费静态交互原型

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`wechat-business-prototype`。
4. AppID 可使用测试号或游客模式。

## 演示闭环

客户：
填写初筛信息 → 初筛通过 → 补充资料 → 提交申请。

管理员：
待审核客户 → 审核通过 → 指派业务员。

业务员：
待接订单 → 接单 → 标记已上门 → 标记办理中 → 选择凭证图片 → 提交公司核销。

管理员：
核销凭证 → 确认核销 → 客户返费记录标记已退费 → 商家佣金记录标记已结算。

商家：
查看当前门店推荐客户、办理进度、预计佣金、锁定佣金和已结算佣金。

## 数据说明

- 初始假数据统一在 `mock` 目录。
- 页面通过 `api/orderApi.js` 读写数据。
- 状态变化保存在微信本地缓存，切换身份后仍可看到同一订单最新状态。
- 后续接云开发时，可优先替换 `api` 层为 `wx.cloud.callFunction`。
