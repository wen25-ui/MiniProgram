# 角色权限矩阵

## 1. 基础规则

- 当前所有角色暂统一采用手机号登录；BOSS 和后台管理员账号由后台预置并绑定手机号。
- 用户只能从商家提供的二维码进入资格申请流程，注册后默认进入用户端。
- 所有角色都可以查看授权范围内的订单状态；权限校验必须由服务端执行。
- 订单、凭证、账单及个人信息遵循最小可见范围；页面隐藏不能替代接口授权。

## 2. 订单与数据范围

| 角色 | 订单范围 | 状态查看 | 敏感信息原则 |
| --- | --- | --- | --- |
| 用户 | 本人订单 | 可查看本人订单完整进度及返现完成入账状态 | 仅本人提交的信息和订单资料 |
| 商家 | 本店归属订单 | 可查看归属客户的订单与佣金状态 | 客户资料按最小必要原则脱敏 |
| 业务员 | 本人负责订单 | 可查看任务、预约、办理和核销状态 | 仅显示上门办理所需资料 |
| 客服 | 本人负责订单 | 可查看审核、联络、派单、凭证和核销状态 | 仅查看审核和协同所需资料 |
| 财务 | 全部订单 | 可查看订单、纸面账单和入账状态 | 使用账单和对账所需资料 |
| BOSS | 全部订单 | 可查看全局业务和账务状态 | 默认只读汇总；明细及导出权限待确认 |
| 后台管理员 | 不默认访问业务订单 | 仅管理授权角色账号 | 可维护商家、业务员、客服账号与基础信息 |

| 查看用户端预计返现 | 是（本人） | 否 | 否 | 否 | 否 | 否 |
| 提供/查看门店专属二维码 | 否 | 是 | 否 | 否 | 否 | 可查看管理入口，具体权限待定 |

后台管理员独立拥有以下权限：

- 查看、新增和修改商家、业务员、客服账号及基础信息。
- 重置上述账号密码、停用或重新启用账号。
- 删除上述账号；删除以逻辑停用实现，历史业务关系和审计记录不删除。
- 不可通过当前管理端创建或管理用户、财务、BOSS、其他后台管理员账号。

## 4. 待确认权限

- 财务账号的创建、审核和停用权限。
- 一个账号拥有多个角色时的角色切换和权限并集规则。
- BOSS 的明细、导出、人员管理和创建其他 BOSS 账号权限。
- 客服在线咨询、工单、电话记录和代客操作权限。
- 导出、附件下载、字段脱敏和数据保存期限。
